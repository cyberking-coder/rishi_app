# Anurag_Rishi — Flutter app

Android + iOS client for videos & audio, with **single-device login** and
**secure (encrypted) in-app downloads**.

## First-time setup

This folder contains the Dart source (`lib/`), `pubspec.yaml`, and lints. The native
platform folders (`android/`, `ios/`) are generated by Flutter — run once:

```bash
cd app
flutter create .          # generates android/ & ios/ without touching lib/
flutter pub get
```

Then run against your backend:

```bash
# Android emulator reaches your host machine at 10.0.2.2 (the default).
flutter run

# Point at a different backend:
flutter run --dart-define=API_BASE_URL=https://api.yourhost.com
```

## Required platform configuration

After `flutter create .`, make these edits:

1. **Internet permission (Android)** — add to `android/app/src/main/AndroidManifest.xml`:
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   ```
2. **Local HTTP during development** — to allow `http://10.0.2.2` (cleartext) on Android,
   set `android:usesCleartextTraffic="true"` on `<application>` in dev. Use HTTPS in
   production and remove it.
3. **Block screenshots / screen recording (recommended)** — for the "can't be saved
   outside the app" goal, prevent screen capture:
   - Android: in `MainActivity`, add `window.setFlags(FLAG_SECURE, FLAG_SECURE)`.
   - iOS: detect `UIScreen.capturedDidChange` and blank sensitive views.

## Architecture

```
lib/
  config/app_config.dart        API base URL (override via --dart-define)
  models/                       User, MediaItem
  services/
    device_service.dart         stable device fingerprint (the single-device lock)
    api_service.dart            HTTP client + typed errors (detects device_locked)
    auth_service.dart           session state, login/register, token persistence
    media_service.dart          catalog fetch
    download_service.dart       AES-encrypted downloads into the private sandbox
  screens/
    login_screen.dart           shows a clear message on device-locked rejection
    register_screen.dart
    home_screen.dart            Videos / Audio tabs, download toggle, opens player
    player_screen.dart          streams online or decrypts the offline copy
  main.dart                     Provider wiring + auth-based routing
```

### How downloads stay "in-app only"

`download_service.dart` writes files to `getApplicationSupportDirectory()/media_vault`,
**AES-256 encrypted** with a per-install key held in the OS secure keystore. That directory
is the app's private sandbox — not visible to the gallery, Files app, or other apps — and the
bytes on disk are ciphertext. Playback decrypts to a short-lived temp file that's deleted
when the player closes. (Screen-recording protection is separate — see step 3 above; full
DRM is a later add-on.)
